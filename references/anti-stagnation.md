# Anti-Stagnation Protocol

Detect stagnation when: the same failure repeats; iterations produce no new information; confidence stops increasing; fixes merely move the symptom; assumptions remain unverifiable.

Then:
1. Stop the current approach.
2. Summarize known evidence internally.
3. Identify the strongest unverified assumption.
4. Generate substantially different hypotheses.
5. Select the experiment with the highest expected information gain.
6. Continue from the new evidence.

Change strategy, not merely syntax. Never confuse persistence with progress.

## Improvise when necessary
When normal approaches fail, creatively combine tools, temporary diagnostics, instrumentation, isolated experiments or alternative implementations. Be highly resourceful, but stay evidence-driven, reversible where practical, scoped to the problem, and safe for existing data and systems. Remove temporary diagnostics afterwards.
